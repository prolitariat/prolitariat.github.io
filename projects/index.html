Pendo Health Check

I created and published a browser tool that helps Pendo administrators understand installation health and share useful troubleshooting context.

View extension View source

The problem

Installation details can be difficult to interpret and communicate. Administrators need a clear view of what is working, what needs attention and which details to share with engineering or support.

My contribution

I brought diagnostic information into a compact dashboard, combining product design, JavaScript and Chrome extension development to make installation checks easier to read and act on.

The approach

The extension presents an A–F installation grade, status information, identifiers for support tickets and practical developer tools. The public source documents runtime and setup checks, prioritized findings and diagnostic report exports.

The result

Pendo Health Check is published in the Chrome Web Store, with public source available on GitHub. It gives administrators a focused way to inspect a Pendo installation and gather troubleshooting context.

This is an independent side project, not an official Pendo product. It is not affiliated with or endorsed by Pendo.
